XHTTP Manager V4.8.8 - TEST REPORT
===================================

Source basis
------------
- User supplied: XHTTP_Manager_V4.8.7.zip
- V4.8.5 was not used.
- Existing V4.8.7 functions were retained; two helper functions were added.

Changes
-------
- Version changed to 4.8.8.
- Manager runtime bootstrap now runs on every menu launch, not only after node installation.
- Persist the exact executing xhttp.sh and resolved core.sh/tunnel.sh into the selected instance library.
- Create/repair the managed /usr/local/bin/xhttp launcher on menu startup.
- Support process-substitution invocation where SELF_DIR is /dev/fd; helper files are resolved from the package, instance library, or RAW_BASE_URL.
- Ensure local_sub_builder.py and local_sub_server.py are installed before subscription generation/service startup.
- Extend subscription builder marker allow-list to 4.8.7 and 4.8.8.
- Preserve the full builder implementation and existing 7 protocol / Tunnel / uninstall functions.
- Instance discovery can re-open a marked existing node when its state/config and dedicated Xray binary are present, even if historical module copies are missing; service path must still match.
- Add Python 3 to dependency detection/installation.

Tests performed
---------------
- bash -n xhttp.sh: PASS
- bash -n core.sh: PASS
- bash -n tunnel.sh: PASS
- Python compile(local_sub_builder.py, local_sub_server.py): PASS
- Xray 26.x REALITY output fixture (PrivateKey + Password (PublicKey) + Hash32): PASS
- Synthetic multi-instance builder test: 4.8.7 and 4.8.8 markers both included; Clash/Mihomo YAML, Sing-box JSON, aggregate subscription generated: PASS
- Local subscription HTTP server test: valid token returns HTTP 200; invalid token returns HTTP 404: PASS
- Startup static integration check: runtime bootstrap, shortcut repair and helper installation are invoked from main: PASS
- Function inventory: original V4.8.7 had 57 shell functions; V4.8.8 has 59; no original function was removed: PASS
- ZIP integrity and SHA256 manifest: checked during packaging

Not tested / limitations
------------------------
- No live access to the user's VPS; /usr/local/bin/xhttp was not installed or executed on that VPS.
- No real systemd/OpenRC service creation/restart, reboot persistence, public port reachability, firewall/security-group change, Cloudflare authentication, or client import/connection was tested.
- The shortcut installer intentionally refuses to overwrite an existing /usr/local/bin/xhttp that cannot be identified as a managed XHTTP launcher.
- Therefore this is locally tested V4.8.8, not a claim of live VPS certification or perfect operation on every host.
