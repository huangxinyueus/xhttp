🔍 核心参数及作用详解

参数项                  设置值                      它的作用是什么？
----------------------------------------------------------------------------------------------------
mode                    "packet-up"                 分包上行模式。对各类固定隧道、中转机和 CDN 网关的
                                                    兼容性最好，能防止双向流在隧道中被强行切断。

scMaxEachPostBytes      1000000 (约1MB)             限制单次上行包的最大字节数。防止瞬间大流量把隧道的
                                                    缓冲区瞬间撑爆而触发限速。

scMinPostsIntervalMs    30 (毫秒)                   控制发包的最小时间间隔。让上行数据以平稳的节奏发送，
                                                    避免流量突发被运营商或网关的 QoS 策略标记。

xmux                    (整个复用模块)              多路复用与连接主动轮换核心。用来彻底根治“刚连上很
                                                    流畅，用一段时间就卡死/掉速”的顽疾。

  ↳ maxConcurrency      "16-32"                     并发子通道数。允许单条隧道同时并发 16 到 32 个子请
                                                    求，提升多线程加载和网页/视频并发时的吞吐量。

  ↳ maxConnections      0                           最大物理连接数。设为 0 代表不设硬性上限，由内核自动
                                                    托管维护（避免设置成具体数字导致客户端报错）。

  ↳ cMaxReuseTimes      "64-128"                    单条连接最大复用请求数。当一条连接处理的请求达到这
                                                    个次数后，会自动废弃并重建，防止单条连接寿命过长。

  ↳ hMaxRequestTimes    "600-900"                   HTTP 层的最大请求复用次数。双重保险，配合请求次数
                                                    到期主动“换马甲”。

  ↳ hMaxReusableSecs    "1800-3000" (30~50分钟)     单条连接的最长存活时间（秒）。即使没达到请求数上限，
                                                    时间到了也会自动无缝切换新连接，避开网关超时拦截。
----------------------------------------------------------------------------------------------------








XHTTP Manager V4.8.7
====================

本版本以用户提供的两个 V4.8.6 包为依据整合：保留可建节点版本的安装主流程，并合入可完整卸载版本的卸载逻辑。不是 V4.8.5 衍生版。

主要修复：
1. 版本号升级为 4.8.7，便于与两个 V4.8.6 包区分。
2. 修复 Xray 26.x REALITY 公钥输出 `Password (PublicKey):` 的解析。
3. 合入 V4.8.6 修改版的实例发现、卸载预检、专用进程清理和旧实例清理逻辑。
4. 识别旧版 V4.8.6 实例标记。
5. 保留 V4.8.6 可建节点版本的安装流程、7 种协议、Tunnel 管理、快捷命令和本地订阅菜单。
6. 保留本地订阅三种格式：Clash/Mihomo、Sing-box、聚合订阅。

安装使用：
- 将 ZIP 解压到服务器目录。
- 在解压目录中以 root 执行：bash xhttp.sh
- 建议不要用 `bash <(curl ...)` 方式启动；快捷命令需要完整包内的 xhttp.sh/core.sh/tunnel.sh 和订阅辅助文件。
- 完整卸载前请确认输入 YES；卸载仅针对 xhttp / xhttp-N 专属命名空间及其专属服务。

安全提醒：
- 不会主动删除 /etc/s-box/ 或 sing-box.service。
- 不会按通用进程名、端口或通用 cloudflared 服务名进行清理。
- 如果检测到符号链接或无法验证归属的服务，会中止卸载以避免误删。

验证范围：本包已做静态语法、Python 编译、密钥解析样例和 ZIP 完整性检查。尚未在真实 Ubuntu/Debian/Alpine VPS 上做端到端安装、重启、客户端连接及卸载验证；不能将本地模拟测试等同于 VPS 实测。
